# 行事曆 Prototype（設計稿）

`web/src/calendar/` 是照這份設計稿改寫的。這個資料夾放的是設計稿原檔，以及**實作跟它哪裡不一樣、為什麼**。

**要看畫面：直接用瀏覽器打開 `prototype.html`**（雙擊就行，不用起伺服器、不用網路）。
三個畫板並排、每個都可以點著操作；執行環境和字型都打包在裡面，所以有 9MB。

| 畫板 | 對應的實作 |
|---|---|
| 手機 App（390×844） | `MobileCalendar.vue` |
| 手機 App · AI 助理開啟（同一個手機畫板，AI 面板打開的狀態） | `MobileCalendar.vue` 的 AI 底部面板 |
| 桌面 Web（1440 寬） | `DesktopCalendar.vue` |

要查某個顏色、間距的原始數值：在畫布上點選元素看屬性，或用瀏覽器開發者工具檢查 `prototype.html`。

設計稿改版時：從畫布重新匯出、覆蓋 `prototype.html`、更新上面的版本號，再對照下面的表看實作要不要跟。

## 跟設計稿不一樣的地方

「刻意」是決定好不做或改掉的；「還沒做」是之後可能補上的；「已做」是原本還沒做、後來補上（但做法跟設計稿不同）的。

### 功能

| 設計稿 | 實作 | 類型 | 原因 |
|---|---|---|---|
| 有全天行程（國慶日、週末登山），週、日視圖上方有「整天」那一列 | 沒有全天行程 | 刻意 | 早先就決定不做：`CalendarEvent` 要多一種「只有日期」的形狀，domain、資料表、重疊查詢、LLM schema 全都要跟著變 |
| 分類有五種，多一個「假日」 | 四種：工作、個人、健康、社交 | 刻意 | 「假日」只用在全天行程上 |
| AI 助理在前端用 regex 假裝解析 | 接後端的 agent（`POST /api/calendar/assistant`）：模型自己決定要反問、查行程、找空檔或提議；提議的行程交給既有的解析流程（JSON Schema、日期對照表、SaidTimes）核對 | 刻意 | 這就是這個專案要學的東西；分工是實測出來的，見 `CalendarAssistant` 的註解 |
| AI 助理還會「查詢某天行程」「找這週空檔」 | 也會，而且時間不確定時會反問（「七點見面」→「早上還是晚上？」） | 已做 | 查詢、找空檔是 agent 的工具；空檔由程式算（`FreeSlots`），「下午」是幾點到幾點由 `DayPeriod` 決定，不讓模型自己說 |
| AI 一次只提一筆行程，卡片只有「加入／取消」 | 一句話可以解析出好幾筆，每筆一張卡片，可以「修改」（帶進新增表單）或「移除」，再一次全部加入 | 刻意 | 後端本來就把一句話拆成多筆；「先預覽、可以改、再確認」是行事曆一開始就定的流程 |
| 分類由關鍵字比對決定 | 由 LLM 判斷（schema 用 enum 鎖住四個值），地點也一起抽出來 | 刻意 | 比關鍵字準；prompt 的調整過程寫在 `ExtractionRequest.instruction()` 的註解 |
| 刪除按一下就刪 | 要按兩次（「刪除」→「確定刪除？」） | 刻意 | 這裡是真的刪資料庫，沒有復原 |
| 新增表單：結束時間不晚於開始就是錯誤 | 結束早於開始 = 結束在隔天（欄位旁標出「隔天」）；一樣才算錯 | 刻意 | 不然「晚上十點到凌晨一點」在表單裡填不出來，但 AI 解析得出來 |
| 「今天」寫死成 2026-10-06，行程是寫死的範例資料 | 真的今天、真的資料庫 | 刻意 | 設計稿只是展示 |
| 讀取失敗、解析失敗沒有畫面 | 有錯誤訊息（「讀不到行程」、AI 回覆「解析失敗」、刪除失敗） | 刻意 | 真的會連不上模型或資料庫 |

### 版面與互動

| 設計稿 | 實作 | 類型 | 原因 |
|---|---|---|---|
| 一週預設從星期日開始（可切換） | 固定星期一開始 | 刻意 | 跟後端給 LLM 的日期表一致：使用者說的「這週」在畫面和模型裡才是同一週 |
| 時間軸從 06:00 畫到 24:00 | 00:00 畫到 24:00，打開時捲到 07:00 | 刻意 | 跨夜行程的凌晨那段（例如前一晚唱到 01:00）在隔天也要畫得出來 |
| 跨天的行程不存在（範例資料都在同一天裡） | 跨夜、跨天的行程在每一天都畫一段，延續過來的那段時間標「↳」、還沒結束的標「隔天」 | 刻意 | 後端允許跨夜行程 |
| 月視圖依月份畫 5 或 6 列 | 固定 6 列（42 格） | 刻意 | 版面不會隨月份跳動；向後端要的期間也固定 |
| 手機版是固定 390×844 的畫板，桌面版是另一張畫板 | 同一個頁面，760px 以下用手機版、以上用桌面版，兩者共用狀態 | 刻意 | 真的網頁要能隨視窗寬度切換；換版面時選的日期、AI 對話都還在 |
| 桌面版視窗變窄時，AI 助理側欄 flex-wrap 掉到下一行 | 1180px 以下 AI 助理改成蓋在右邊 | 刻意 | 實作的頁面是固定高度（各欄自己捲動），掉到下一行就看不到了 |
| 主題選擇只存在畫面狀態裡 | 存在瀏覽器的 localStorage，重新整理還在 | 刻意 | 個人偏好，不必存到後端 |

### 沿用設計稿、沒有改的

主題的四組顏色與分類顏色（深淺兩組）、字型（Manrope + Noto Sans TC）、各元件的尺寸與間距、
月格最多三筆再「+N 更多」、點日期進日視圖、手機版月曆的分類圓點與當日清單、
新增表單的欄位與預設值（選的那天 10:00–11:00、工作）、存檔後打開該行程的詳情、重疊行程並排的排法。
